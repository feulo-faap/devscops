Ataque Adversarial — FGSM

Fast Gradient Sign Method

O que estamos demonstrando?

Um classificador de Machine Learning pode ser enganado modificando apenas alguns pixels da imagem de entrada.

A alteração pode ser praticamente imperceptível para uma pessoa, mas suficiente para alterar a decisão tomada pelo modelo.

xadv = x + ε · sign(∇x J(θ, x, y))

O FGSM utiliza o gradiente da função de perda para descobrir em qual direção os pixels devem ser alterados para aumentar o erro do classificador.

5. O que o atacante fez?

  1. O atacante apresenta uma imagem ao classificador.
  2. O modelo calcula sua previsão e a função de perda.
  3. O gradiente da perda em relação aos pixels indica como cada pixel deve ser alterado.
  4. O FGSM utiliza apenas o sinal do gradiente.
  5. O parâmetro ε controla o tamanho da perturbação.
  6. A imagem modificada é enviada novamente ao classificador.
  7. O modelo pode tomar uma decisão diferente mesmo quando a alteração é praticamente imperceptível para uma pessoa.
Ponto importante

O FGSM não modifica o modelo. Ele modifica deliberadamente a entrada do modelo para induzir uma classificação incorreta.
