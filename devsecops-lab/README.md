# DevSecOps Lab

Projeto desenvolvido para a disciplina Fundamentos de Segurança e DevSecOps.

## Instalação

```bash
python -m venv .venv
```

Linux

```bash
source .venv/bin/activate
```

Windows

```cmd
.venv\Scripts\activate
```

Instale as dependências

```bash
pip install -r requirements.txt
```

Crie o banco

```bash
python criar_db.py
```

Execute

```bash
python app.py
```

Acesse

http://localhost:5000
